How this runs:

MediaPipe BlazeFace finds faces, then the ear model runs on a square crop around each one. An ear is a median 14 px when a whole frame is squeezed into the 128 px input, and 32 px inside a face crop, which is worth mAP@0.5 0.31 → 0.58.

Running the ear model on the whole frame is what this demo used to do; that path is still in the API, documented in docs/README.md.

Note: an ear whose face is missed never reaches the second stage — 1.3% of validation images at the default face threshold.
